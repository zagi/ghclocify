Mapping

Choose the Clockify workspace and project the entries go to, and how a day is shaped: each day with activity gets entries starting at the start time, adding up to the hours per day, in the timezone the dates are read in.

This workspace is on Clockify's Free plan, which allows only 30 API requests per hour. Large imports may be slow or need to be split up.

Preview & import

One row per issue per day. Untick what you don't want, adjust hours if needed, then import. Days that already have entries in this project are marked as duplicates and skipped.
